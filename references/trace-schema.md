# Trailblazer `trace.json` Schema Specification

`trace.json` is the core data exchange artifact generated by the AI agent during repository investigation. 
It captures everything discovered about a specific issue in a structured, verified schema. The local validator (`scripts/compile.py`) checks this file against actual repository files and compiles it into the standalone visualization page (`assets/template.html`).

---

## Top-Level Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `version` | `string` | Yes | Schema version, currently `"1.0.0"`. |
| `repository` | `string` | Yes | Target repository identifier (e.g., `owner/repo` or full URL). |
| `issue` | `object` | Yes | Metadata about the issue being analyzed. |
| `summary` | `object` | Yes | High-level 3-point briefing (`problem`, `rootCause`, `patchTarget`). |
| `aiPolicy` | `object` | No | Project's AI contribution rules detected from repo governance docs. |
| `evidence` | `object` | Yes | Reproduction status, test executions, and verification confidence. |
| `trail` | `array` | Yes | 3 to 6 ordered code stops showing the path from entry to issue origin. |
| `flow` | `object` | No | Sequence of component interactions and call path. |
| `codeMap` | `object` | No | Hierarchical view of involved files and modules. |
| `changeBlueprint` | `object` | Yes | Invariants, affected scope, checklist, and verification tests. |
| `metrics` | `array` | No | Quantitative breakdowns (e.g. failure counts, timing, matrices). |
| `glossary` | `object` | No | Domain/repo-specific terms explained for newcomers. |
| `contextNotes` | `array` | No | Safety advisories, environment prerequisites, or architecture notes. |
| `maintainerQuestions`| `array`| No | Clarifying questions ready to post on the issue thread. |
| `irrelevantFiles` | `array` | No | Files that appear related but are proven out-of-scope. |

---

## Detailed Object Definitions

### 1. `issue`
```json
{
  "id": "104",
  "url": "https://github.com/acme-org/project/issues/104",
  "title": "Token refresh fails silently on socket reconnection",
  "category": "bug", // "bug" | "flaky-test" | "feature" | "performance" | "security" | "refactor" | "docs"
  "commit": "a3b89ef48123cde89710f"
}
```

### 2. `summary` (High-Level Briefing)
Each field should be concise and plain-language:
```json
{
  "problem": "Active WebSocket connections drop silently when tokens expire without retrying authorization.",
  "rootCause": "The reconnect loop bypasses auth middleware and fails with unhandled 401 response.",
  "patchTarget": "src/transport/socket_client.py: reconnect handler should trigger refresh_token() before handshake."
}
```

### 3. `aiPolicy` (AI Policy Radar)
```json
{
  "status": "allowed", // "allowed" | "restricted" | "prohibited" | "unspecified"
  "sourceFile": "CONTRIBUTING.md",
  "summary": "AI tools permitted provided generated code is reviewed and noted in PR description.",
  "rawExcerpt": "Contributors may use AI assistants but must clearly disclose usage in their pull request description."
}
```

### 4. `evidence` (Proof & Reproduction)
```json
{
  "level": "reproduced-isolated", // "reproduced-real" | "reproduced-isolated" | "static-analysis" | "inferred"
  "confidence": 0.95, // 0.0 to 1.0
  "commandsRun": [
    "pytest tests/test_transport.py -k test_reconnect_auth_expired"
  ],
  "outputSnippet": "AssertionError: expected WebSocketState.CONNECTED but got WebSocketState.CLOSED",
  "whatRan": "Isolated unit test simulating token expiration during reconnect attempt.",
  "whatSkipped": "End-to-end multi-tenant cluster test (requires external AWS mock container).",
  "notes": "Isolated test confirmed the unhandled 401 code path."
}
```

### 5. `trail` (Code Stops: 3 to 6 items)
```json
[
  {
    "id": "stop-1",
    "role": "entry", // "entry" | "transit" | "origin" | "patch"
    "title": "WebSocket reconnect trigger",
    "description": "Triggered when network heartbeat drops.",
    "file": "src/transport/socket_client.py",
    "lineStart": 45,
    "lineEnd": 58,
    "highlightLines": [52, 53],
    "explanation": {
      "simple": "When disconnected, the client initiates a background reconnection loop.",
      "detailed": "reconnect_async() loop initiates socket connection directly without checking session validity.",
      "deep": "Historically added in v1.2 to eliminate socket handoff latency, but skipped auth token re-signing."
    },
    "code": {
      "lines": "async def reconnect_async(self):\n    self.state = WebSocketState.CONNECTING\n    await self._raw_connect(self.endpoint)",
      "pointer": "Bypasses self.auth_provider.ensure_valid_token()"
    }
  }
]
```

### 6. `flow` (Interaction Sequence)
```json
{
  "actors": ["ClientApp", "SocketManager", "AuthService", "RemoteGateway"],
  "interactions": [
    {
      "from": "ClientApp",
      "to": "SocketManager",
      "action": "disconnect detected",
      "stopId": "stop-1",
      "isFailurePoint": false
    },
    {
      "from": "SocketManager",
      "to": "RemoteGateway",
      "action": "handshake with expired token",
      "stopId": "stop-2",
      "isFailurePoint": true,
      "error": "HTTP 401 Unauthorized"
    }
  ],
  "omittedSteps": [
    "TLS socket negotiation details",
    "Heartbeat timer cancellation"
  ]
}
```

### 7. `changeBlueprint` (Fix Blueprint & Guardrails)
```json
{
  "targetFiles": ["src/transport/socket_client.py"],
  "mustKeepTrue": [
    "Reconnection backoff delay intervals must not reset on auth check failure.",
    "Active event listeners on the socket manager must be preserved across reconnects."
  ],
  "permittedToChange": [
    "Allow reconnect loop to await token refresh before invoking _raw_connect."
  ],
  "verificationCommand": "pytest tests/test_transport.py -k test_reconnect",
  "suggestedTestCases": [
    "Simulate expired token during reconnect; assert refresh_token is called once."
  ],
  "checklist": [
    "Check if refresh_token can throw AuthError and handle cleanly",
    "Verify no infinite reconnection loop if refresh credentials are revoked",
    "Ensure tests pass without network access"
  ]
}
```
